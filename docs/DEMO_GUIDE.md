# Demo guide

Open the client and begin on the dashboard. Show expected rent, collection, balances, occupancy, attention accounts, and recent activity. Select Properties to show Muto Buildings and City View, then Tenants or Arrears to search records. Use Record payment to update a tenant balance and open the generated print-ready receipt. Use Maintenance to create a request, Reports to open summaries, and Audit Logs to show accountability.

Demo data is fictional. Provision an owner account in the database using a bcrypt hash and document its password only in a secure handoff channel.
